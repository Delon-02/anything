Sprite character walking animation - transparent PNGs

All frames are individual PNG files with transparent backgrounds.
WALK_RIGHT: 4 frames facing right.
WALK_LEFT: 4 frames facing left.

Unity:
1. Extract this ZIP.
2. Import the PNG files into Assets.
3. Set Texture Type to Sprite (2D and UI).
4. Set Sprite Mode to Single.
5. Use each sequence in the Animation window.

Each frame has a consistent 270x420 transparent canvas to help keep alignment stable in Unity.
